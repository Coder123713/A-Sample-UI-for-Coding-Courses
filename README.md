🔧 Project Description:

I created a basic UI prototype for a website called CodeBright, designed to offer free coding courses for kids and adults. The interface includes a homepage, course section, enrollment page, and a mock payment page. It’s structured for Python, HTML, CSS, and JavaScript courses across three levels: Beginner, Intermediate, and Advanced. This project focuses only on the front-end design and layout — no backend or functionality is included yet. The project was designed and developed by sstt or me.
